# MyRolePi OS

Десктопный конструктор настольных ролевых систем и кампаний для мастера (модуль лаунчера **Asteia Alltools**).
Система описывается данными: типы сущностей (персонаж, космический корабль, база, город — любые), поля, формулы,
действия, виды карточек. Расширяется плагинами. Языки: русский и английский (легко добавлять новые).

## Запуск
```
npm install
npm run dev        # разработка (Vite + Electron)
npm run build && npm start
npm test           # тесты ядра
```
Из лаунчера: `--launcher --data-dir <путь> --plugins-dir <путь> --lang ru` (см. `asteia.module.json`). Лаунчер ещё не создан — этот контракт задаёт модуль, лаунчер будет писаться под него.

## Платформы, сборка и обновления
Windows (установщик + portable), macOS (dmg, x64/arm64), Linux (AppImage, deb): `npm run dist:win | dist:mac | dist:linux`
(кросс-сборка не гарантируется — собирайте на целевой ОС или в CI).
- **Само приложение никогда не обновляется и не ходит в сеть за обновлениями.** Хотите обновления — используйте лаунчер Asteia Alltools; не хотите — скачайте нужную версию вручную из GitHub Releases и оставайтесь на ней.
- **Лаунчер** читает фид `UpdateFeed` (`src/core/updates.ts`: версии, changelog, сборки по платформам), ставит обновления и показывает changelog. Changelog также лежит в приложении (раздел «О программе»).

## Лаунчер (`launcher/`)
Минимальный лаунчер Asteia Alltools: список модулей (`launcher/modules.json`), выбор любой версии из GitHub Releases,
установка, запуск, переключение и удаление версий, changelog из описания релиза. Запуск из исходников: `cd launcher && npm install && npm start`. Готовые сборки: тег `lan-v0.0.1` (workflow `launcher.yml`) → Releases.
Модуль запускается с `--launcher --data-dir --plugins-dir --lang`. Для Facet OS укажите `repo` в `modules.json`.
Файлы релиза выбираются автоматически: Windows — `*-portable.exe` или установщик `*Setup*.exe` (ставится тихо в каталог версии), Linux — `*.AppImage`, macOS — `*.zip` или `*.dmg` (.app копируется из образа) (`npm run dist` уже называет их так).

## Структура
- `src/core` — движок без привязки к UI: кубики, формулы, схема системы, вычисление полей, валидатор, i18n, контракт плагинов.
- `src/main` — Electron: окно, хранилище JSON, загрузка плагинов.
- `src/renderer` — интерфейс (React).
- `docs/AI_PLUGIN_GUIDE.md` — файл для нейросети, чтобы она писала плагины; `docs/FORMULAS.md` — справочник.
- `examples/` — пример системы «Космическая опера» (персонаж, корабль, колония).

## Что умеет
- **Игровые системы.** Любые типы объектов (персонаж, корабль, город, база…), параметры, формулы, макросы, кубики (`4d6kh3`, взрывные, Fudge).
- **Карточки.** Конструктор на сетке: блоки перетаскиваются и растягиваются, у типа несколько видов карточки, фон-картинка или цвет, 5 готовых оформлений.
- **Действия.** Атаки, проверки, лечение: формулы с вопросами при броске и эффектами; журнал бросков.
- **Кампании.** Герои и существа, лист и карточка, галерея карточек и бестиарий, трекер боя (инициатива, раунды, здоровье), заметки мастера со связями и поиском.
- **Темы оформления** (тёмные и светлые), русский и английский, импорт и экспорт систем и кампаний в JSON.
- **Плагины.** Свои функции формул, блоки карточек, готовые системы, переводы и темы; `docs/AI_PLUGIN_GUIDE.md` можно отдать нейросети.

## Статус
Основной сценарий готов: система → карточки и действия → кампания → бой. Подробности реализации, ограничения и инструкции для следующей смены: [docs/DEVELOPMENT_HANDOFF.md](docs/DEVELOPMENT_HANDOFF.md).

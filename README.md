# MyRolePi OS

Десктопный конструктор настольных ролевых систем и кампаний для мастера (модуль лаунчера **Asteia Alltools**).
Система описывается данными: типы сущностей (персонаж, космический корабль, база, город — любые), поля, формулы,
действия, виды карточек. Расширяется плагинами. Языки: русский и английский (легко добавлять новые).

## Запуск
```
npm install
npm run dev        # разработка (Vite + Electron)
npm run build && npm start
npm test           # тесты ядра
```
Из лаунчера: `--launcher --data-dir <путь> --plugins-dir <путь> --lang ru` (см. `asteia.module.json`). Лаунчер ещё не создан — этот контракт задаёт модуль, лаунчер будет писаться под него.

## Платформы, сборка и обновления
Windows (установщик + portable), macOS (dmg, x64/arm64), Linux (AppImage, deb): `npm run dist:win | dist:mac | dist:linux`
(кросс-сборка не гарантируется — собирайте на целевой ОС или в CI).
- **Автономно:** приложение само проверяет фид обновлений (`--update-feed <url>` или `MYROLEPI_UPDATE_FEED`) и показывает changelog в разделе «О программе».
- **Из лаунчера:** лаунчер читает тот же фид (`UpdateFeed`, по сборке на платформу), сам ставит обновления и показывает changelog; приложение в этом режиме само ничего не качает.

## Структура
- `src/core` — движок без привязки к UI: кубики, формулы, схема системы, вычисление полей, валидатор, i18n, контракт плагинов.
- `src/main` — Electron: окно, хранилище JSON, загрузка плагинов.
- `src/renderer` — интерфейс (React).
- `docs/AI_PLUGIN_GUIDE.md` — файл для нейросети, чтобы она писала плагины; `docs/FORMULAS.md` — справочник.
- `examples/` — пример системы «Космическая опера» (персонаж, корабль, колония).

# Формулы и кубики / Formulas & dice

## Кубики
| Запись | Значение |
|---|---|
| `d20`, `3d6` | обычные кубики |
| `d%` | d100 |
| `4dF` | кубики Fudge (−1/0/+1) |
| `4d6kh3` / `2d20kl1` | оставить N старших / младших |
| `4d6dl1` / `4d6dh1` | отбросить N младших / старших |
| `3d6!` | взрывные кубики (максимум → бросок ещё раз) |
| `roll(n, s)` | то же, что `nd s`, но с вычисляемыми n и s |

## Выражения
`+ - * / % ^`, сравнения `== != < > <= >=`, логика `&& || !`, тернарный `a ? b : c`, скобки.
Строки — в `"..."` или `'...'`.

## Переменные
Имя поля сущности (`str`, `сила`), путь через точку (`ship.hull`), допустим префикс `@`.
Вычисляемые поля могут ссылаться друг на друга; циклы обнаруживаются при проверке системы.

## Функции
`floor ceil round abs sqrt min max sum avg clamp if len roll`.
Свои функции: **макросы системы** (`macros` в системе) и **плагины** (`host.registerFormulaFunction`).
`if(условие, a, b)` вычисляет только выбранную ветку — кубики из другой ветки не бросаются.
